# vps-mitsi 

Assess the carbon footprint of IT services. The app is deployed on GitHub Pages.

## Requirements

- [npm](https://docs.npmjs.com/) Node.js package manager
- Make


## Deploying locally


From the cloned repository's root, install the frontend dependencies:

```bash
make install
```


### Frontend

Run:

```bash
make run-frontend
```

The website will be available at [http://localhost:9000](http://localhost:9000).
